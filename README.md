# Mystery Shopper · Andres Nino

Versión estática para GitHub Pages del dashboard de Mystery Shopper.

## Publicación

1. Crea un repositorio nuevo en GitHub.
2. Sube `index.html` y `yango_logo.png` a la raíz del repositorio.
3. En **Settings → Pages**, selecciona **Deploy from a branch**, la rama `main` y la carpeta `/ (root)`.
4. Abre la dirección que GitHub Pages genere.

El dashboard lee la pestaña pública `Andres Nino` del Google Sheet y abre la carpeta de Drive asignada a este equipo para cargar facturas y comprobantes.

Clave de acceso visual: `Andres2026`.

La clave está incluida en el código del sitio y no protege datos sensibles. GitHub Pages publica archivos estáticos, por lo que una persona con conocimientos técnicos puede verla o eludirla.
